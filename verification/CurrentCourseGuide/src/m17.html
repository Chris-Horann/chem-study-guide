Learn

Two nonmetals can combine in more than one ratio: sulfur and oxygen form both SO2 and SO3. There are no ion charges to fix the ratio, so a covalent name has to state how many atoms of each element the molecule contains. Greek number prefixes do that.

What we observe

The same two elements make different compounds: SO2 and SO3 are two different substances, and sulfur and fluorine form S2F2 (Day 8 p.13).

What we write

SO2, sulfur dioxide; SO3, sulfur trioxide; S2F2, disulfur difluoride (Day 8 p.13).

What the particles are doing

A covalent compound is made of molecules: atoms held together by shared electrons (Day 7 p.14). The prefixes count the atoms of each element in one molecule.

Source: Day 8 p.12–13; Day 7 p.14.

Understand

prefix + first element, then prefix + second element-ide

The rule “The name of a binary covalent compound starts with the name of the parent element of the first element in the formula… followed by the name of the parent element of the second element with ending changed to –ide. We use prefixes to indicate the number of each kind of atom in the formula. Exception: we do not use ‘mono’ for the first element” (Day 8 p.12).

Vowels: “When prefixes ending in o- or a- (such as mono- and tetra-) precede a name that begins with a vowel (such as oxide), the o or a at the end of the prefix is deleted” (PDF p.188): N2O is dinitrogen monoxide, N2O4 dinitrogen tetroxide, P2O5 diphosphorus pentoxide (Sample Ex. 4.3). The slides don't state this rule, so this guide accepts both forms.

Which element comes first: “the element to the left of or, if the elements are in the same group, below the other one in the periodic table” (PDF p.220). Oxides of the halogens other than fluorine are written with O last, as in the textbook's own dibromine monoxide, Br2O (PDF p.189).

Recognize it

  • Only nonmetals in the formula → a covalent name with prefixes.
  • A name with prefixes → each prefix is a subscript: dinitrogen trioxide → N2O3.
  • A metal anywhere in the formula → back to the ionic rules (§4.3, ionic; transition metals).

Common mistakes

  • Putting “mono” on the first element (“monocarbon monoxide”).
  • Leaving out the prefixes (“phosphorus chloride” could be PCl3 or PCl5).
  • Using Roman numerals for nonmetals (“sulfur(VI) oxide”).
  • Attaching a prefix to the wrong element (N3O2 for dinitrogen trioxide).
