Learn

Repeating a measurement answers two questions. How much do the results scatter? That's the standard deviation, a measure of precision. And could the true value plausibly be what we expect? The confidence interval answers that, which judges accuracy. A suspicious point can be tested once, with Grubbs' test, instead of being quietly dropped.

What we observe

A lab checks its method on a control sample of known creatinine concentration (0.681 mg/dL) and gets 0.685, 0.676, 0.669, 0.688, and 0.692 mg/dL.

What we write

x̄ = 0.6820 mg/dL; s = 0.0094 mg/dL; 95% confidence interval: 0.6820 ± 0.0116 mg/dL, which contains 0.681, so the method is accurate.

Where the scatter comes from

Random error, such as dust, vibration, or reading a scale, pushes results up or down equally, giving a bell-shaped (normal) distribution. About 68% of results fall within one s of the mean.

Source: textbook §1.9, PDF p.65–71 (printed 31–37); the creatinine example is the textbook's worked illustration (PDF p.65–67).

Understand

x̄ = Σxi / n

The arithmetic mean (Eq. 1.5).

s = √[ Σ(xi − x̄)2 / (n − 1) ]

Steps Take each deviation from the mean, square it, add the squares, divide by n − 1, and take the square root (Eq. 1.6). Report x̄ ± s, with s rounded to the mean's last decimal place.

Why n − 1 The mean was calculated from the same data, which uses up one degree of freedom. (The textbook states the formula; this reason is background.)

μ = x̄ ± t·s/√n

Meaning The range that has (say) a 95% chance of containing the true mean μ (Eq. 1.7). t comes from Table 1.5, using n − 1:

Decision If a known value falls inside the interval, the analysis is judged accurate at that confidence level.

Z = |xi − x̄| / s

Grubbs' test (Eq. 1.8): if Z exceeds the reference value in Table 1.7 (at 95%: n = 5 → 1.715; n = 6 → 1.887; n = 10 → 2.290), the point is an outlier and may be discarded. Use the test only once per data set. Discarding data without a valid reason is unethical.

Common mistakes

  • Dividing by n instead of n − 1.
  • Looking up t with n instead of n − 1 (Table 1.7 uses n itself).
  • Calling precise data accurate.
  • Dropping an “ugly” value without a test.
